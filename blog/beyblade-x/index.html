Beyblade X 入門：規格、部件同設計全解

2026-10-22 · BeyHK

  • Beyblade X 係 Takara Tomy 嘅第四代 Beyblade，2023年7月15日喺日本推出，系列入面每隻陀螺都由三個可以互換嘅部件組成：Blade、Ratchet 同 Bit。
  • 部件編碼講晒隻陀螺嘅配置：好似 3-60 呢類 Ratchet 數字代表 3 個接觸點同 6.0 mm 高度，結尾字母就係 Bit，所以 Dran Sword 3-60F 用嘅係 Flat 平腳尖。
  • 場地入面嘅 X-Celerator Rail 會同 Bit 上嘅齒輪咬合，觸發 Xtreme Dash——呢一代獨有嘅爆發加速。
  • 正式比賽以 4 分定勝負：Xtreme Finish（極限擊飛）3 分、Over/Knockout Finish（擊出場外）2 分、Burst Finish（爆開擊潰）2 分、Spin (Survivor) Finish（旋轉持久勝出）1 分。
  • 部件喺 BX、UX 同 CX 系列之間完全通用，所以買一隻都係幫你擴大選擇，唔會箍住你。

Beyblade X 嘅規格其實就係三個部件加一個場地機關。如果你攞起個盒，唔知 Ratchet 上面啲數字咩意思、唔知邊款 Bit 啱你風格，又或者唔明點解新代打得比之前 Burst 更重手，呢篇攻略會帶你行匀成個系統：三件式結構、點樣睇 3-60F 呢類編碼、三條產品線各有咩賣點，同埋邊啲先至係真正嘅使錢陷阱。Takara Tomy 喺 2023年7月 推出呢條產品線，作為第四代 Beyblade，用更快、更講技術嘅玩法取代 2015 年嘅 Burst 系統 [1]。睇完呢一版，任何 Beyblade X 產品說明你都睇得明，買嘅係咩一清二楚。

咩係 Beyblade X？

Beyblade X 係一個對戰式陀螺系統，每隻陀螺都由三個獨立部件組裝：上面係 Blade、中間係 Ratchet、尖端係 Bit；對戰就喺設有加速軌道嘅場地入面，以擊倒、爆開或者旋轉時間分勝負。

Takara Tomy 將佢定位為第四代：1999 年嘅初代 Beyblade、2008 年嘅 Metal Fight、2015 年嘅 Burst，再到 2023年7月 嘅 X [2]。呢個系列同時都係品牌 25 週年紀念，所以首批產品除咗新設計，亦主打重做一啲玩家最愛嘅陀螺。

三件式系統

  • Blade：又大又重嘅外層，承載住圖案同大部分重量。佢嘅形狀決定戰鬥類型：尖銳接觸邊係 Attack、寬闊牆身係 Defense、流線弧度係 Stamina [3]。
  • Ratchet：連接 Blade 同 Bit 嘅中間鎖。佢決定陀螺嘅高度同防爆接觸點嘅數量 [3]。
  • Bit：接觸場地嘅腳尖。佢嘅形狀決定移動同持久力，好多 Bit 嘅底部都有驅動 Xtreme Dash 嘅齒輪 [4]。

點樣睇 3-60F 呢類部件編碼

Ratchet 數字代表接觸點數量同以毫米十分位計嘅高度。3-60 嘅 Ratchet 有 3 個鎖定位同埋 6.0 mm 高；4-80 就係 4 個鎖定位、8.0 mm 高。結尾字母係 Bit：F 係 Flat、T 係 Taper、B 係 Ball、N 係 Needle 咁樣 [5]。所以首發產品線嘅 Dran Sword 3-60F，就係 Dran Sword Blade 配 3 接觸點、6.0 mm Ratchet，再加一個 Flat 攻擊型腳尖。Ratchet 數字越大通常代表陀螺越高、越難被由下而上擊中；接觸點越多通常防爆能力越好。

點解 X-Celerator Rail 咁重要

呢條軌道係呢一代嘅招牌。Bit 上面嘅齒輪同場地 Xtreme Line 嘅齒軌咬合，場地嘅結構會以機械方式推動陀螺向前，突發一段 Takara Tomy 稱之為 Xtreme Dash 嘅加速 [4]。由於效果嚟自齒輪實際咬合而唔係摩擦，所以只有 Bit 嘅齒輪真正咬到軌道先會觸發，呢點正正解釋咗點解 Flat 同 Gear 腳尖嘅 Bit 喺攻擊打法入面咁吃香。首發產品線每隻陀螺售 ¥1,980 並跟拉尺發射器，令呢個對戰系統嘅入場門檻平得少有 [1]。

三條產品線：BX、UX 同 CX

系列 編碼前綴 係咩 部件組合 最啱邊類人
Basic BX 由推出以來嘅標準產品，正統三件式系統 Blade + Ratchet + Bit 第一次入手、款式最多
Unique UX 破格造型同機關設計；自 2026年2月 起，部分 Expand Blade 將 Ratchet 整合入 Blade Blade (+integrated Ratchet) + Bit 收藏家、鍾意玩機關嘅人
Custom CX 模組化分層系統，有 Lock Chip、Main Blade 同 Assist Blade；部分陀螺將 Ratchet 同 Bit 融合 Lock Chip + Main Blade + Assist Blade (+integrated Bit) 追求深度改裝嘅比賽玩家

部件跨系列通用：UX Blade 可以配 BX Ratchet 同 Bit，所有發射器同場地全部啱用 [3]。一個實際貼士：BX-08 3-on-3 Deck Set 售 ¥3,960，係一次過集齊三隻完整陀螺最抵嘅方法——官方 3-on-3 規則係咁要求㗎 [6]。

比賽點樣計分

正式規例比賽採用 4 分制 [7]：

  • Xtreme Finish（將對手送入 Xtreme Zone）：3 分
  • Over/Knockout Finish（將對手擊出至 Over Zone）：2 分
  • Burst Finish（對手陀螺爆開散件）：2 分
  • Spin/Survivor Finish（對手先停止旋轉）：1 分

對戰賽採用 3-on-3 戰鬥，每組三隻 Bey，同一部件唔可以喺三隻陀螺入面出現多過一次，唔同色都唔得 [7]。正因為呢個組牌規則，部件通用性喺實戰中先至咁重要。

優點、缺點、風險同限制

  • 優點：全系列通用嘅三件式改裝、完整 Starter 入場價低，仲有軌道機關拉高技術上限。
  • 缺點：Random Booster 產品只有部件冇發射器，所以淨係買一盒 Booster 係打唔成嘅 [6]。CX 多咗一層結構，成本同複雜度都增加，新手暫時唔需要。
  • 限制：正式比賽只承認正版 Beyblade X 部件；拆解、改裝同影響性能嘅噴漆一律禁止，違規者會被裁判取消資格 [7]。舊代產品唔可以喺官方活動使用。
  • 買家風險：炒賣同假貨常見到 Takara Tomy 都要公開警告非官方產品，所以記得喺持牌零售商度買 [8]。

點樣開始玩 Beyblade X

  1. 買一盒 Starter（首發 BX-01 至 BX-04：Dran Sword、Hells Scythe、Wizard Arrow、Knight Shield）。Starter 係唯一跟發射器嘅級別 [6]。
  2. 加一個 Beyblade X 場地。Dash 機關一定要用 Xtreme Line 軌道；普通 Burst 場地係觸發唔到嘅 [4]。
  3. 學識睇盒上編碼，打之前已知隻陀螺咩類型：Blade 名 + Ratchet 接觸點-高度 + Bit 字母 [5]。
  4. 徒手組裝：上面 Blade、中間 Ratchet、下面 Bit。唔使用工具。
  5. 用官方計分打 4 分制，記低賽果，咁你先睇到自己隻組合輸喺邊啲對局 [7]。

常見問題

3-60F 呢類編碼咩意思？

Ratchet 數字代表接觸點數量同以毫米十分位計嘅高度，字母就係 Bit。3-60F 即係 3 鎖定位、6.0 mm 嘅 Ratchet 配 Flat 腳尖 [5]。數字越大坐得越高；鎖定位越多越防爆。

新手應該買邊條 Beyblade X 產品線？

由 BX，即 Basic Line 開始。佢係最平嘅完整系統，用標準三件式組合，之後部件同其他系列全部互通 [5]。想玩深度改裝嗰陣先考慮 CX。

Beyblade X Starter 賣幾多錢？

Takara Tomy 日本產品線嘅 Starter 售 ¥1,980 至 ¥2,750，視乎系列同盒裝大細，入面跟發射器。Random Booster 大約 ¥1,400 至 ¥1,600，但係只有部件 [6]。

Beyblade X 同舊代 Beyblade 兼唔兼容？

唔兼容。正式比賽只承認 Beyblade X 嘅陀螺、發射器同場地；Burst、Metal Fight 同初代產品喺官方活動一律禁用 [7]。

可唔可以混合唔同 Beyblade X 系列嘅部件？

可以。Blade、Ratchet、Bit、發射器同場地喺 BX、UX、CX 之間全部互通，只有少部分較新嘅陀螺將 Ratchet 整合入 Blade 或 Bit [3]。記住一條組牌規則：官方 3-on-3 比賽入面，三隻 Bey 唔可以重用同一部件 [7]。

Xtreme Dash 係咩？

佢係 Bit 齒輪同場地 Xtreme Line 軌道咬合時觸發嘅爆發加速。咬合係機械式嘅，所以取決於 Bit 嘅設計，而唔係單靠發射力度 [4]。

網上買 Beyblade X 有咩風險？

主要風險係假貨同炒賣價。Takara Tomy 有發佈非官方產品通告，亦已針對品牌周邊嘅欺詐活動採取措施 [8]。喺持牌零售商度買，見到平到離譜嘅貨就當係警號。

總結

對新手最緊要嘅一個心得：買之前先睇部件編碼，因為 Ratchet 高度同 Bit 字母喺你發射之前已經話你知隻陀螺會點郁。你而家可以做嘅就係揀一盒啱你風格嘅 BX Starter——攻擊揀 Flat Bit，防守同持久揀 Needle 或 Ball——再同朋友用官方計分打 4 分制。當你想記錄賽事、追蹤邊啲組合贏得多嘅時候，BeyHK app 會記低每一場對戰，同埋幫你同香港玩家排名，等你嘅部件選擇有真數據做依據：beyhk.sh。
