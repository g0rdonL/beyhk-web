模型完整資料：規格・零件・設計重點

2026-11-17 · BeyHK

模型編碼係 Beyblade X 最被低估嘅入手技能：一組字已經寫明隻陀螺屬邊條產品線、配咩零件、高度幾多，連軸心特性都寫喺尾。呢篇模型資料總覽會由零開始拆解 BX、UX、CX 三條產品線嘅命名規則，讀明 Starter、Booster、Random Booster 同套裝嘅分別，再對埋官方零件點數解釋規格，最後俾你一個按情境揀模型嘅決定框架。睇完你攞住任何一個型號，例如 BX-54 或者 CX-20，都可以自己講出盒入面有咩、值唔值買。

重點一覽

  • 每隻 Beyblade X 陀螺由刃擊環（Blade）、固鎖（Ratchet）、軸心（Bit）三件零件組成，換任何一件，性能即時改變。
  • 產品線分三條：BX 基本線、UX 獨特線、CX 客製線；CX 嘅刀刃可以再拆成四層零件，係可玩性最高嘅結構。
  • Starter（¥1,980 起）包陀螺加發射器；Booster（¥1,400）淨係陀螺；Random Booster（¥1,400）一盒隨機一隻。
  • 模型編碼直接寫出規格：3-60F 即 3 個接觸位、6.0 mm 高、Flat 軸心；0-70LP 即 0 個接觸位、7.0 mm 高、可切換模式嘅 LP 軸心。
  • 最新 BX 模型係 BX-54 凱旋超神 0-70LP，2026年11月21日 發售，官方定價 ¥1,600。

咩係 Beyblade X 模型？

模型係 Beyblade X 對戰陀螺嘅正式產品單位：每個型號一組編碼，標明產品線、陀螺名同零件配置，一隻陀螺由刃擊環、固鎖、軸心三件零件組成，組合不同性能即時改變，官方稱呢個系統做 Gear 結構。呢套設計令同一隻陀螺可以拆件重組，亦係 Beyblade X 同舊代產品最核心嘅分別。

Takara Tomy 用三條產品線分開定位：BX 係標準基本線，UX 主打破格造型同機關，CX 就係可以拆到最盡嘅客製線。三條線嘅零件喺固鎖同軸心層面大致互通，但刀刃結構各有各嘅設計邏輯，下文會逐條拆。

點樣睇模型編碼：由型號拆解命名規則

一個完整型號例如「BX-54 凱旋超神 0-70LP」，其實分四段資訊：前綴講產品線，數字講流水編號，中段編碼講固鎖規格，尾段字母講軸心類型。逐段睇。

系列前綴：BX、UX、CX 有咩分別

前綴 產品線 刀刃結構 定位
BX Basic 基本線 一體式刃擊環，金屬同樹脂分佈平均 標準三件式，款式最多，新手起點
UX Unique 獨特線 Expand Blade：固鎖整合入刀刃 破格造型同特殊機關
CX Custom 客製線 刀刃可拆四層（紋章鎖、主刃、輔刃、金屬層、Over 層） 改裝自由度最高

前綴決定咗你買返嚟嘅嘢係咩結構：BX 係最正統嘅三件式；UX 為咗將金屬放到刀刃外圍，把固鎖同刀刃合成一件；CX 就反方向行，把刀刃拆開做幾層，令同一隻陀螺有幾種砌法。

產品類型：Starter、Booster、Random Booster 同套裝

同一條產品線入面，產品類型決定盒入面有咩。官方產品列表將商品分做 Starter、Booster、Random Booster、套裝同工具幾類，價錢由 ¥700 嘅工具到 ¥8,200 嘅大套裝都有。買之前認清楚類型，係唔好買錯嘅第一步。

產品類型 盒入面有咩 官方定價 適合邊個
Starter 陀螺 + 發射器 ¥1,980 至 ¥2,420 第一次入手
Booster 淨係陀螺 ¥1,400 已有發射器，想砌機
Random Booster 隨機一隻（一盒多款抽一） ¥1,400 想平價補零件
套裝／Stadium Set 戰鬥盤 + 陀螺 + 發射器組合 ¥3,960 至 ¥8,200 想一次過有齊對戰環境

資料來源：Takara Tomy 官方產品列表，2026年11月16日 查證。

要注意 Starter 嘅價差主要來自零件複雜度：基本 BX Starter 多數 ¥1,980，部分配置複雜嘅型號去到 ¥2,420；Booster 固定 ¥1,400，即係話你用 Booster 買陀螺、另外配發射器，長遠可以慳唔少。

零件編碼點樣讀：以 0-70LP 為例

固鎖編碼頭一個數字係接觸位數量，後面兩個數字係高度，單位係毫米十分位：3-60 即 3 個接觸位、6.0 mm 高；0-70 即 0 個接觸位、7.0 mm 高。接觸位越多，爆裂抗性通常越高；高度越大，同對手碰撞嘅位置越高。

軸心字尾係移動特性：F（Flat）係攻擊向平面，T（Taper）係斜面，B（Ball）係穩定圓頭，N（Needle）係持久針尖。以 BX-54 凱旋超神 0-70LP 為例，LP 係一個可以按發射方式切換動向嘅平衡軸心，官方數值攻擊 30、防禦 15、持久 30、加速 25、爆裂抗性 80，配上攻守兼備嘅刃擊環，令成隻陀螺可以在猛攻同固守之間切換。

三條產品線嘅規格同設計重點

BX 基本線：金屬發射鈎，平衡耐用

BX 嘅設計重點係穩：發射鈎用金屬製，令重量分佈平均，刀刃嘅金屬集中喺中央位置，剛性高，碰撞時表現穩定。三件式結構最直觀，刃擊環決定碰撞面，固鎖決定高度同接觸位，軸心決定移動同持久。限量復刻系列都由 BX 線出發，例如 BX-48 嗰批金屬塗層復刻版，收藏價同實戰價都齊。

UX 獨特線：固鎖整合入刀刃

UX 嘅招牌係 Expand Blade：為咗將金屬配到刀刃外圍，官方把固鎖同刀刃整合成一件，等特殊造型同機關有更多空間。代價係固鎖唔再係獨立零件，換高度要成組刀刃換。改造套裝例如 UX-10 就係呢條線嘅代表，一盒幾隻陀螺加發射器，專為砌機同對戰而設。

CX 客製線：可以拆到四層嘅刀刃

CX 把刀刃拆成紋章鎖、主刃、輔刃幾層，再加金屬層同 Over 層，砌返一個完整刃擊環，之後先接固鎖同軸心。以 CX-20-01 鳳凰戰壓 WH 為例，一隻陀螺由六件零件組成：紋章鎖、主刃、支援刃、金屬刃擊環、Over 刃擊環、核輪同軸心，層層可以單獨換。呢個結構令 CX 陀螺對戰可以一隻三砌，同一盒已經有三種配置，係現時改裝自由度最高嘅產品線。

由第一代到第四代：模型系統點演變

Beyblade X 係系列第四代：1999 年初代確立改造玩法，2008 年 Metal Fight 代主打金屬碰撞，2015 年 Burst 代加入爆裂機制，到 2023年7月15日 推出嘅 X 代就用軸心齒輪咬合場地軌道嘅 X-Dash 加速，重新定義速度。了解第一代到第四代嘅演變線，你就會明點解 X 代零件咁強調咬合、高度同碰撞面：成個對戰系統都圍繞呢三樣嘢運行。

模型規格點樣讀：點數、高度同旋轉方向

每件零件都有官方點數：攻擊、防禦、持久三項基本值，軸心另加速性能同爆裂抗性，固鎖另有高度。以 BX-54 為例，刃擊環攻擊 38、防禦 35、持久 27，核輪 0-70 高度 70，軸心 LP 爆裂抗性 80，三件數值疊起來就係成隻陀螺嘅體質。數值唔係絕對強弱，係幫你配型：想打持久就揀高持久軸心，想扛爆裂就睇爆裂抗性同接觸位數量。

旋轉方向都寫喺規格入面：大部分刃擊環係右迴旋，部分特殊型號係左迴旋，左迴旋同右迴旋對撞嘅碰撞結果同右對右完全唔同，砌 deck 時要留意配對。

買邊隻模型好？三個情境嘅決定框架

先畀結論：第一次入手買 BX Starter；想砌機就買 Booster 拆件；想平價湊 deck 就用 Random Booster 補位；想要完整對戰環境先考慮套裝。按情境對號入座：

情境 最啱嘅選擇 點解
第一次接觸 Beyblade X BX Starter（¥1,980 起） 陀螺加發射器齊料，開盒即射
已有發射器，想認真砌機 Booster（¥1,400） 淨買陀螺，零件直接落 deck
平價湊齊三隻 deck Random Booster（¥1,400） 一盒隨機一隻，抽中即用
要完整對戰環境 套裝（¥3,960 起） 連戰鬥盤同發射器一次到位

砌 deck 有一個關鍵策略：比賽常用三隻陀螺，三隻嘅零件配搭盡量分散，避免三隻都依賴同一批零件，等對手一種打法就剋死成副 deck。Random Booster 係好嘅補件來源，例如 CX-17 一盒八款，中獎率公開，用嚟補特定零件好過做主力。想知自己配出嚟嘅組合喺社區入面定位如何，可以參考香港排名榜同賽事資訊再調整。

點樣開始砌你嘅第一隻模型

  1. 揀一隻 BX Starter 做起點：有陀螺有發射器，編碼簡單易讀，先熟習射法。
  2. 買一個對戰盤：官方場地有加速軌道，冇軌道嘅普通盤發揮唔到 X-Dash。
  3. 學基本射法：發射器平行托喺盤面，拉短繩一次過發射，先練平射，再學咬軌道。
  4. 記錄同實戰：每場對戰記低配置同結果，贏輸都要記，先至知道邊件零件要換。

常見問題

BX-54 係咩模型？

BX-54 凱旋超神 0-70LP 係一隻 Booster 產品，2026年11月21日 發售，官方定價 ¥1,600。佢係攻守切換嘅平衡型：上段刃擊環平滑向上延伸主打攻擊，下段反擊刃可以彈開低高度對手，配合可切換動向嘅 LP 軸心，按發射方式在猛攻同固守之間轉換。

Starter 同 Booster 應該買邊種？

從來未有發射器就買 Starter：¥1,980 起，陀螺發射器齊料。已有發射器就買 Booster：¥1,400 淨買陀螺，直接拆件落 deck。簡單計數：兩隻 Starter 嘅錢，夠買一隻 Starter 加三隻 Booster，零件換購效率高好多。

模型編碼中間嗰兩個數字係咩意思？

嗰組數字係固鎖規格：頭一個數係接觸位數量，後面兩個數係高度，單位毫米十分位。3-60 即 3 個接觸位、6.0 mm 高；0-70 即 0 個接觸位、7.0 mm 高；M-85 就係 8.5 mm 高嘅大型固鎖。數字直接影響碰撞高度同爆裂抗性。

一隻模型可以拆成幾多件零件？

BX 同 UX 基本係三件：刃擊環、固鎖、軸心；UX 嘅 Expand Blade 把固鎖整合入刀刃，所以獨立零件係兩組。CX 最多，可以拆到六件：紋章鎖、主刃、輔刃、金屬層、Over 層加埋砌成刃擊環，再接固鎖同軸心，層層獨立可換。

Random Booster 值唔值得買嚟砌 deck？

值得做補件，唔值得做主力。一盒 ¥1,400 隨機一隻，中獎率官方公開，你係博特定零件而唔係博隻獎品陀螺。砌 deck 嘅零件需求好明確，用 Random Booster 補位係效率玩法，但主力配置應該用 Starter 或者 Booster 直接買齊。

香港買 Beyblade X 模型貴唔貴？

日本官方定價係基準：Starter ¥1,980 起、Booster ¥1,400、Random Booster ¥1,400。香港零售價會因水貨渠道、匯率同店舖定價有出入，熱門型號同限量版經常溢價，落單前最好格價兩三間舖，亦要留意代理版同日版嘅包裝分別。
